# Ficha Automática (RPG Tormenta-20)

## Descrição do Projeto

Sistema de criação e armazenamento de fichas de RPG de mesa, baseado no sistema de Tormenta 20 com conteúdos apenas do livro base edição jogo do ano. Biblioteca de poderes, habilidades e magias integrada na interface,  com seção de gráficos estimando patamares de dano por uso de habilidades.

## Funcionalidades
✔️ Armazenamento de Fichas em bibliotecas de usuário <br>
✔️ Dashboard com especificações do personagem <br>
✔️ Sistema de Login com contas pessoais para acesso das fichas de qualquer dispositivo
